# WIREFRAME.md — MockMarket UI

다크 테마 기준. 공통 NavBar는 모든 페이지 상단 고정.

---

## 공통 — NavBar

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  ◈ MockMarket          [ Home ]  [ Trade ]  [ News ]       YEAR 1 · Q2      │
│                                                          [ 다음 분기로 진행 → ]│
└─────────────────────────────────────────────────────────────────────────────┘
  로고                   탭 네비                          현재 분기 + 진행 버튼
```

- 로고: 좌측 고정
- 탭: 현재 페이지 탭에 하이라이트 (하단 언더라인 또는 배경)
- 우측: 현재 분기 텍스트 + [다음 분기로 진행 →] 버튼 (emerald)
- 진행 중(뉴스 생성)일 때 버튼 → 스피너 + "뉴스 생성 중..." 비활성화
